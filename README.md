# Runax landing page

Static HTML, CSS and JavaScript implementation based on the supplied landing-page PDF, using the supplied logo and locally stored photos from https://www.runaxinstitute.com/.

Run `npm run dev`, then open http://127.0.0.1:4173. Deploy the `dist` directory to any static host.

Enquiry forms validate required fields and prepare email drafts addressed to admission@runaxinstitute.com. They do not store or send submissions. Apply Now and course links use the institute's existing website. The sample testimonials and unsupported statistics in the PDF were replaced with sourced institute information and associates.

Includes responsive navigation, smooth anchor scrolling, animated gradients, text entrances, scroll reveals, an accessible native gallery dialog, and reduced-motion support.
