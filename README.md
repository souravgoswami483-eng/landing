# Runax landing page

Static HTML, CSS and JavaScript implementation based on the supplied landing-page PDF, using the supplied logo and locally stored photos from https://www.runaxinstitute.com/.

Run `npm run dev`, then open http://127.0.0.1:4173. Deploy the `dist` directory to any static host.

Enquiry forms validate required fields and prepare email drafts addressed to admission@runaxinstitute.com. They do not store or send submissions. Apply Now and course links use the institute's existing website. The testimonials and Why Choose Us statistics use the supplied PDF, as confirmed by the user. The mobile contact bar uses +91 89616 29333 for calls and WhatsApp.

Includes responsive navigation, smooth anchor scrolling, animated gradients, text entrances, scroll reveals, an accessible native gallery dialog, and reduced-motion support.

Updated: student-final.png CTA cutout, glassmorphism forms with Submit labels, three student testimonials, animated statistics and icons, and 16 associate logos.
